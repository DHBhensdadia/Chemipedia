ChemiPedia

An open chemistry reference: all 118 elements, the table that organises them, and the glossary behind the vocabulary.

This is the foundation build. It exists to prove the pipeline end to end — a route declared in the manifest is rendered to static HTML at build time and served from a plain directory — before any of the design or the chemistry data is written. The design system comes next, then the element data, then the periodic table itself.

What is already in place

  • a route manifest that the build, the tests and the development server all read from one place;
  • a dependency-free build that renders every declared route to a static HTML file;
  • a dependency-free development server that resolves directory-style URLs and builds on demand;
  • a test suite that runs on the Node test runner, with nothing to install.

How this document is produced

The markup above is authored in source/pages/home.html. The build wraps it in the document skeleton and writes the result to dist/index.html, so no output file is ever edited by hand.
